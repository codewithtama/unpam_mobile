# Pembaruan UNPAM Mobile v1.0.14

Pembaruan UNPAM Mobile v1.0.14:

- Fitur Baru: Pop-up Otomatis Akses Cepat Biometrik (Quick Access Prompt). Setelah berhasil login pertama kali di Mentari, aplikasi otomatis menampilkan penawaran praktis untuk mengaktifkan login sidik jari. Kredensial disimpan terenkripsi di dalam Keystore hardware perangkat.
- Real-Time Auth Detection: Mencegat token sesi secara instan pada aplikasi Single Page Application (React SPA Mentari) sehingga prompt muncul seketika tanpa perlu me-reload halaman.
- Jaminan Zero Overflow: Menerapkan penanganan layout responsif pada seluruh dialog, modal bottom sheet, banner, dan form agar terbebas sepenuhnya dari pesan RenderFlex Overflow pada berbagai ukuran layar maupun skala font besar.
- Peningkatan reliabilitas dan kestabilan WebView Mentari UNPAM.
